# Топ-3 ИИ-моделей по версии Artificial Analysis — рассказывает крабик Claude

Анимированный ролик длиной ровно **60 секунд**: HTML + CSS + JavaScript + GSAP 3,
сцена 1920×1080 (16:9). Персонаж и сцены нарисованы кодом (SVG + CSS); график —
настоящий скриншот с artificialanalysis.ai (`assets/aa-intelligence-index.png`), анимации
наложены поверх него.
Ведущий — пиксельный оранжевый крабик Claude.

## Данные

Источник: [artificialanalysis.ai/models](https://artificialanalysis.ai/models),
график **Artificial Analysis Intelligence Index v4.3.2** (набор по умолчанию «27 of 704 models»).

## Как открыть

1. Дважды щёлкните по `index.html`: локальный сервер не нужен, скрипты подключены обычными `<script src>`.
2. Нужен интернет: GSAP грузится с `cdnjs.cloudflare.com`, шрифты Nunito и PT Serif — с Google Fonts.
3. Ролик стартует сам. Лучше смотреть в полноэкранном режиме браузера (F11). Сцена сама масштабируется под окно и показывается с чёрными полями (letterbox).

### Управление

Панель внизу экрана прячется через 2 секунды бездействия и появляется снова, если подвинуть мышь.

| Действие | Как |
|---|---|
| Play / Pause | кнопка ► / ❚❚ или **пробел** |
| С начала | кнопка ↺ |
| Перемотка | ползунок, или **←** / **→** (±5 с) |
| Главы | риски над ползунком: Интро, Что такое AA, Диаграмма, 3, 2 и 1 место, Финал |
| Запись видео | кнопка **● Запись** |

## Как записать видео

1. Откройте `index.html` в **Chrome** или **Edge** (Firefox тоже умеет, но без автообрезки кадра).
2. Разверните окно, а лучше включите полноэкранный режим (F11).
3. Нажмите **● Запись** и в диалоге выберите **эту вкладку**.
4. Панель и курсор спрячутся, ролик начнётся с 0:00, а через 60 секунд запись остановится сама.
   Файл `top3-ai-artificial-analysis-<дата>.webm` скачается автоматически.

Если браузер умеет Region Capture (Chrome 104+), кадр обрезается ровно по сцене 16:9.
Иначе записывается вся вкладка, поэтому лучше включить F11.

Нужен MP4? Сконвертируйте файл: `ffmpeg -i top3.webm -c:v libx264 -crf 18 -pix_fmt yuv420p top3.mp4`

## Звук

Готовое видео со звуком: `video/top3-ai-artificial-analysis.mp4` (H.264 + AAC, 60 с).

Звук целиком синтезируется на **Python** (только numpy), в браузере ничего не играет:

1. **Разметка.** Анимации отмечают звуковые события через `Cues.cue(...)` из `js/cues.js`:
   прыжки, щелчки, печать текста, переходы, барабанную дробь, корону, конфетти и т.д.
2. **Выгрузка.** `node audio/export_cues.js` сохраняет события с абсолютным временем
   в `audio/cues.json`. Нужен Playwright: `npm i -D playwright && npx playwright install chromium`.
3. **Синтез.** `python3 audio/make_audio.py` пишет `audio/soundtrack.wav` (48 кГц, стерео):
   - чиптюн-музыка 120 BPM: аккорды I–V–vi–IV, бас-треугольник, арпеджио, мелодия, шумовые барабаны.
     Аранжировка меняется по сценам: разгон перед дробью, тёмная пауза перед 1 местом,
     фанфары, разрешение в тонику к финальному щелчку;
   - эффекты, привязанные к событиям с точностью до сэмпла.
4. **Вклейка в видео.** `python3 audio/make_audio.py --mux video/top3-ai-artificial-analysis.mp4`
   добавляет дорожку через ffmpeg, видео не перекодируется.

Если поменялись тайминги в сценах, повторите шаги 2–4: звук подстроится сам.

## График — настоящий скриншот

В сценах с диаграммой показывается сам скриншот графика с сайта, без перерисовки.
Анимации живут в слоях поверх него, строго по координатам 27 столбиков:
- **рост:** кусок «пустого» кадра закрывает столбик и уезжает вверх, открывая настоящий;
- **затемнение:** белая вуаль над столбиком и логотипом;
- **подсветка, медали, корона:** накладываются по координатам столбиков.

Новый скриншот (того же вида «27 of 704 models») подключается так:

```
python3 assets/make_chart_assets.py путь/к/скриншоту.png
```

Скрипт обновит оба PNG и напечатает координаты столбиков. Их нужно вставить в `SHOT.bars`
в `js/chart.js`, а топ-10 и баллы обновить в `js/data.js`.

## Как обновить цифры, если рейтинг изменится

Все цифры лежат **только в `js/data.js`**:

- `date`, `indexVersion`: дата снимка и версия индекса (выводятся в подписи и на графике);
- `models`: топ-10 по порядку с сайта. `name`, `variant`, `lab`, `score`; `noApi: true` даёт столбик «в клеточку»;
- `labs`: цвета лабораторий. Если появилась новая лаборатория, добавьте её сюда;
- `benchmarks`: из каких тестов состоит индекс (10 карточек во второй сцене);
- `extras`: числа для «фишек» в карточках топ-3 (результаты отдельных тестов, цены);
  тексты фишек собираются из них в блоке `D.facts` в конце файла.

Что пересчитывается само:
- столбики, подписи, счётчики и карточки мест;
- разрыв «от №1 до №8» и «отрыв лидера»;
- плашка «столько же, сколько у №…» при равенстве баллов;
- реакция крабика на 1-м месте: если первой окажется не модель Claude, он не смущается,
  а честно поздравляет победителя (ветка `isClaude` в `scenes.js → scene6`).

Шутки в 3-й и 2-й сценах написаны под конкретные модели (Muse Wonder Full без API; Sonnet,
обогнавший Opus в Terminal-Bench). Если сменятся лидеры, перепишите эти реплики в `js/scenes.js`.

## Структура

```
index.html        разметка сцены и панели управления
css/style.css     все стили, CSS-переменные цветов
js/data.js        данные бенчмарка — единственное место с цифрами
js/cues.js        разметка звуковых событий (сам звук — в audio/make_audio.py)
js/crab.js        пиксельный SVG-крабик: моргание, ходьба боком, щелчки, эмоции, реквизит
js/chart.js       настоящий скриншот графика + слои анимации по координатам его столбиков
assets/aa-intelligence-index.png        скриншот графика с сайта (16.10.2026), как есть
assets/aa-intelligence-index-empty.png  тот же кадр без столбиков — для анимации роста
assets/make_chart_assets.py             готовит оба файла и меряет координаты столбиков
js/scenes.js      scene1()…scene7(), каждая возвращает gsap.timeline(), плюс эффекты и облачка
js/main.js        мастер-таймлайн с метками, масштабирование, управление, запись
audio/export_cues.js  выгрузка звуковых событий в audio/cues.json
audio/make_audio.py   синтез музыки и эффектов на numpy, вклейка в видео
audio/cues.json       события ролика с абсолютным временем
video/…mp4            готовое видео 1920×1080, 60 fps, со звуком
```

### Тайминг

| Время | Сцена | Переход в следующую |
|---|---|---|
| 0–6 с | Интро | крабик утаскивает экран клешнёй как шторку |
| 6–15 с | Что такое Artificial Analysis | круговая маска «из глаза» |
| 15–25 с | Диаграмма топ-10 | зум камеры в тройку лидеров |
| 25–34 с | 3 место | смахивание со спидлайнами |
| 34–43 с | 2 место (карточка падает с пылью) | затемнение и прожектор |
| 43–54 с | 1 место: прожектор, корона, конфетти | пиксельное рассыпание |
| 54–60 с | Финал | щелчок, экран схлопывается в точку |

Перемотка работает в обе стороны: все анимации лежат в одном мастер-таймлайне,
а «случайные» эффекты строятся из детерминированного генератора.
